# Hierarchical world compilation

This note is the research rationale for Basalt's three-tier compiler. It keeps
the useful findings from procedural-world and modular-kit work while removing
the old assumption that an agent should author a complete scene or gameplay
script in one pass.

## Compiler tiers

### Macro: continuous world fields

The macro planner owns world bounds, regions, adjacency, water tables,
elevation, slope, moisture, material weights, navigability, and route corridors.
`TerrainFieldArtifact` is the single sampled field. Region weights are
normalized once and reused by terrain geometry, materials, and scatter. The
field is partitioned on shared source samples so chunk boundaries are exact.

### Meso: families and assemblies

The meso planner resolves open-vocabulary requirements into a small number of
asset families per region. A family carries a shared silhouette language,
material roles, metric envelope, socket grammar, and bounded variants. Typed
assemblies build repeated structures from those families; neural workers may
produce a few missing archetypes offline, but never emit per-instance code.

Structural regions use a Lloyd-relaxed Centroidal Voronoi Tessellation. Given
sites `p_i` and a density-weighted cell `V_i`, each iteration replaces the site
with its weighted centroid and quantizes shared joint elevations to the declared
step `Δh`:

```text
p_i <- centroid_w(V_i)
h_joint <- round(h_joint / Δh) * Δh
```

The quantized joints are the only geometry inputs passed to typed assembly
recipes. A model never authors a wall or roof transform directly.

### Micro: conditioned population

The micro compiler integrates density over valid surfaces and subtracts routes,
clearance masks, and exclusions. Poisson, cluster, along-path, surface-grid,
and socket distributions produce transforms from deterministic seeds. Every
sample goes through `PlacementSurfaceIndex`, so sloped support and normals are
part of the same authority as terrain raycasts.

Hydrology uses Priority-Flood for drainage and river carving. The carved
channel is excluded from population by a buffer radius `R_buffer`; the
exclusion is soft for density and hard for collision and route clearance.

## Why families instead of individual props

A catalog may contain thousands of meshes, but the model should select roles,
families, density fields, and hero slots. Offline catalog indexing is linear;
production retrieval applies hard bounds and capability filters before a small
contact-sheet shortlist. Accepted archetypes are content-addressed and reused
across every instance and region. This makes scene complexity scale with
families and chunks rather than model calls per object.

## Modular interfaces

Socketed construction uses immutable profile geometry and explicit coordinate
frames. Boundaries are sliced and welded to the profile, then checked for
closure, support, collision, and clearance. A neural mesh can propose a visual
component, but it cannot claim a socket, pivot, articulation, or function until
those interfaces pass deterministic checks.

The public research interfaces map directly to the runtime contracts:

```ts
export interface SocketContract {
  socketId: string;
  semanticRole: string;
  gender: "male" | "female" | "neutral";
  localFrame: {
    origin: [number, number, number];
    normal: [number, number, number];
    upVector: [number, number, number];
  };
  boundaryProfile: {
    shape: "polygon" | "rectangle" | "circle";
    dimensions: [number, number];
    planarTolerance: number;
  };
  snapPolicy: {
    angularStepDegrees: number;
    allowInversion: boolean;
    weldDistanceThreshold: number;
  };
}

export interface TrimSheetMappingProfile {
  trimAtlasHandle: string;
  bandId: string;
  targetTexelDensity: number;
  energy: number;
}

export interface PreparedModularKitArtifact {
  kitId: string;
  styleContractHash: string;
  archetypeHandles: readonly string[];
  socketRegistryHash: string;
  trimSheetMappings: readonly TrimSheetMappingProfile[];
  hash: string;
}
```

For each UV island `k` and trim band `T_i`, the hotspot mapper minimizes

```text
E(k, T_i) = α | ln(AR_k / AR_T_i) |
          + β | Area_3D(k) / (W_T_i H_T_i) - 1 |
```

where `α` and `β` are bound in the trim-sheet profile. A mapping is rejected
when its measured texel density or overlap exceeds the delivery policy.

## Connector and runtime boundary

Basalt emits partitioned world deltas through the Studio connector. ChangeHistory
transactions, detached preflight, and readback reconciliation remain the final
write authority. Gameplay scripts consume exported anchors, routes, and sockets
from an external project; they are not generated by the world compiler.

## Evidence retained

Research prototypes, model qualifications, catalog measurements, and creator
reviews remain evidence inputs. They are never runtime authority. A world build
is accepted only when its field, family handles, transforms, chunk manifests,
and connector receipt hash back to the same immutable plan.
